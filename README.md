# JSP Form Processing Example

## 📌 Overview
This project demonstrates the basics of **JavaServer Pages (JSP)** by processing user input from an HTML form. Users enter two numbers, and the JSP page receives the request, performs the calculation, and displays the result.

## 🚀 Features
- HTML Form
- JSP Page Processing
- GET Request Handling
- Request Parameter Retrieval
- Dynamic Output using JSP
- Basic Arithmetic Operation

## 🛠️ Technologies Used
- Java
- JSP (JavaServer Pages)
- HTML
- Apache Tomcat 8
- Eclipse IDE

## 📂 Project Structure
```
JSPproject
│── src/main/webapp
│   ├── index.html
│   └── new.jsp
```

## ▶️ How to Run
1. Import the project into Eclipse.
2. Configure Apache Tomcat Server.
3. Run the project on Tomcat.
4. Open:
```
http://localhost:8080/JSPproject/
```
5. Enter two numbers and click **Submit**.
6. The JSP page processes the request and displays the result.

## 📚 Concepts Covered
- JavaServer Pages (JSP)
- HTML Forms
- Request Parameters
- JSP Scriptlets
- Dynamic Web Applications
- GET Method

## 💡 Learning Outcome
This project provides a simple introduction to JSP by demonstrating how user input is collected through an HTML form and processed on the server to generate dynamic content.
